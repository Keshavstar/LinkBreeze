# LinkBreeze Runtipi App Store

A [Runtipi](https://runtipi.io) v4+ app store hosting
[LinkBreeze](https://github.com/OmniRise/LinkBreeze), the self-hosted Linktree
alternative.

## Add this store to Runtipi

1. Open your Runtipi dashboard → **Settings** → **App Stores**
2. Click **Add App Store**
3. Paste: `https://github.com/OmniRise/LinkBreeze-Runtipi-Store`
4. Give it any name, then install **LinkBreeze** from the apps list

## Apps

- **linkbreeze** — one public page for all your links, with a real admin
  dashboard: privacy-first analytics, QR codes, 11 themes, link scheduling,
  and a migration wizard. Single container, SQLite included, setup wizard on
  first open.

## Maintenance

The app definition is mirrored from
[`packaging/runtipi/`](https://github.com/OmniRise/LinkBreeze/tree/main/packaging/runtipi)
in the main repository. Version bumps land there first during each release,
then sync here.
